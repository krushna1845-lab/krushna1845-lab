## 🟣 About Me

I'm a second-year **Computer Engineering** student at **Indira College of Engineering and Management (ICEM), Pune**, passionate about designing scalable, secure backend systems. My primary focus is building robust applications with **Java** and **Spring Boot**, while expanding into DevOps, containerization, and system design.

I enjoy turning ideas into working software: REST APIs, authentication systems, relational database design, containerized deployments, and automated pipelines. I completed a **Diploma in Computer Engineering** at Guru Gobind Singh Polytechnic (2022–2025) before continuing into B.Tech, giving me a practical, hands-on foundation.

- ☕ Backend developer specializing in **Java & Spring Boot**
- 🛠️ Building **REST APIs** and exploring microservices architecture
- 🐳 Learning **Docker, Kubernetes**, and cloud-native deployment fundamentals
- 🔐 Interested in security-minded engineering, including the MidBrain Antivirus project
- 🧩 Continuously improving **DSA** and backend system-design skills
- 🎯 Goal: build reliable, large-scale distributed systems

**Open to:** Software Engineering Internships, Backend / Java development roles, and security-adjacent engineering work.
